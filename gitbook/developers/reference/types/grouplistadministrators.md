# GroupListAdministrators

Arguments for members.list_admins in Super Groups with group moderation enabled. Current membership, permissions and promotion ancestry control the operation.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `include_bots` | boolean | No | Whether to include other bot administrators. They are excluded by default. The default is `false`. |
