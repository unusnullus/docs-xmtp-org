# GroupPromoteMember

Arguments for members.promote in Super Groups with group moderation enabled. Current membership, permissions and promotion ancestry control the operation.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `rights` | [GroupAdminRights](groupadminrights.md) | Yes | These are the default administrator permissions that your bot requests when added to a chat. |
