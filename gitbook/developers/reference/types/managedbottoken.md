# ManagedBotToken

The current secret token of a bot managed by the authenticated caller. Keep it private and do not cache this response.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `token` | string | Yes | Current secret bot token. Do not share, log or cache it. The minimum length is 1 character. |
