# ReplyMarkup

A keyboard or reply input instruction to attach to a message.

You receive one of the following forms. Required fields apply within each form.

- `type` is `"inline_keyboard"`: [InputInlineKeyboard](inputinlinekeyboard.md).

- `type` is `"reply_keyboard"`: [InputReplyKeyboard](inputreplykeyboard.md).

- `type` is `"remove_keyboard"`: [InputRemoveKeyboard](inputremovekeyboard.md).

- `type` is `"force_reply"`: [InputForceReply](inputforcereply.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
