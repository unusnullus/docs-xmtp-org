# SetAdminRights

The default administrator rights your bot requests for groups or channels.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `rights` | [AdminRights](adminrights.md) | Yes | These are the default administrator permissions that your bot requests when added to a chat. |
