# InputDraftRichButton

An interactive button embedded in rich content. Use this node in a temporary rich draft.

Supply exactly one of the following forms. Required fields apply within each form.

- When `type` is `"callback"`, use [InputDraftRichInlineButtonCallback](inputdraftrichinlinebuttoncallback.md).

- When `type` is `"url"`, use [InputDraftRichInlineButtonUrl](inputdraftrichinlinebuttonurl.md).

- When `type` is `"copy_text"`, use [InputDraftRichInlineButtonCopyText](inputdraftrichinlinebuttoncopytext.md).

- When `type` is `"disabled"`, use [InputDraftRichInlineButtonDisabled](inputdraftrichinlinebuttondisabled.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
