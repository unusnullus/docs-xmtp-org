# InputDraftRichInlineBold

Inline text displayed in bold. Use this node in a temporary rich draft.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [InputDraftRichText](inputdraftrichtext.md) | Yes | The inline text displayed in bold. |
| `type` | `"bold"` | Yes | The rich content node type is bold. |
