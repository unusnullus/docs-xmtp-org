# InputEntity

An explicit formatting span in text input. Use UTF-16 offsets and lengths, and omit the markup format.

Supply exactly one of the following forms. Required fields apply within each form.

- When `type` is `"mention"`, use [InputEntityMention](inputentitymention.md).

- When `type` is `"hashtag"`, use [InputEntityHashtag](inputentityhashtag.md).

- When `type` is `"cashtag"`, use [InputEntityCashtag](inputentitycashtag.md).

- When `type` is `"bot_command"`, use [InputEntityBotCommand](inputentitybotcommand.md).

- When `type` is `"url"`, use [InputEntityUrl](inputentityurl.md).

- When `type` is `"email"`, use [InputEntityEmail](inputentityemail.md).

- When `type` is `"phone_number"`, use [InputEntityPhoneNumber](inputentityphonenumber.md).

- When `type` is `"bold"`, use [InputEntityBold](inputentitybold.md).

- When `type` is `"italic"`, use [InputEntityItalic](inputentityitalic.md).

- When `type` is `"underline"`, use [InputEntityUnderline](inputentityunderline.md).

- When `type` is `"strikethrough"`, use [InputEntityStrikethrough](inputentitystrikethrough.md).

- When `type` is `"spoiler"`, use [InputEntitySpoiler](inputentityspoiler.md).

- When `type` is `"code"`, use [InputEntityCode](inputentitycode.md).

- When `type` is `"pre"`, use [InputEntityPre](inputentitypre.md).

- When `type` is `"blockquote"`, use [InputEntityBlockquote](inputentityblockquote.md).

- When `type` is `"expandable_blockquote"`, use [InputEntityExpandableBlockquote](inputentityexpandableblockquote.md).

- When `type` is `"text_link"`, use [InputEntityTextLink](inputentitytextlink.md).

- When `type` is `"text_mention"`, use [InputEntityTextMention](inputentitytextmention.md).

- When `type` is `"date_time"`, use [InputEntityDateTime](inputentitydatetime.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
