# InputRichInlineStrikethrough

Inline text displayed with a strikethrough. Use this node when sending rich content.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [InputRichText](inputrichtext.md) | Yes | The inline text displayed with a strikethrough. |
| `type` | `"strikethrough"` | Yes | The rich content node type is strikethrough. |

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
