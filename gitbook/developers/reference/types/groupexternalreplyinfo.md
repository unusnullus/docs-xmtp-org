# GroupExternalReplyInfo

An external reply summary. Registration of this model does not grant cross-chat reading or enable a producer; availability requires the independent admitted source and destination.

You receive one of the following forms. Required fields apply within each form.

- A private or otherwise hidden source summary: [GroupExternalReplyHidden](groupexternalreplyhidden.md).

- An admitted public group or channel source, with both canonical source IDs: [GroupExternalReplyVisible](groupexternalreplyvisible.md).
