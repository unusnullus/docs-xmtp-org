# InputInlineButton

An inline button to attach to a message. Its type chooses its action.

Supply exactly one of the following forms. Required fields apply within each form.

- When `type` is `"callback"`, use [InputInlineButtonCallback](inputinlinebuttoncallback.md).

- When `type` is `"url"`, use [InputInlineButtonUrl](inputinlinebuttonurl.md).

- When `type` is `"copy_text"`, use [InputInlineButtonCopyText](inputinlinebuttoncopytext.md).

- When `type` is `"disabled"`, use [InputInlineButtonDisabled](inputinlinebuttondisabled.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
