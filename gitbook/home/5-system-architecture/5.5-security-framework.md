# 5.5 Security framework

Security is integrated into every part of the ARX system. It protects communication, governance, and economic mechanisms from both technical and operational risks.

Main safeguards:

* **End-to-end encryption**: Ensures only sender and recipient can access message content.
* **Local key storage**: Private keys never leave the user’s device.
* **Validator integrity**: Economic penalties discourage downtime or misconduct.
* **Independent audits**: Regular external reviews confirm protocol safety and code accuracy.
* **Device protection**: Mobile clients use secure enclaves and sandboxing where available.

This layered security model ensures that privacy and reliability are maintained at all times.
