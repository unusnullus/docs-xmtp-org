# ChecklistContent

The checklist content returned within a message.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `checklist` | [Checklist](checklist.md) | Yes | This contains the checklist title, tasks, and collaboration settings. |
| `type` | `"checklist"` | Yes | The content type is checklist. |
