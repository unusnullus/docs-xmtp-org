# RichInlineButton

An interactive button within inline rich text.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `button` | [RichButton](richbutton.md) | Yes | This defines an interactive button embedded in rich text. |
| `type` | `"button"` | Yes | The button action type is button. |
