# GroupSetChatPhoto

Arguments for chats.set_photo in Super Groups with group moderation enabled. Current membership, permissions and promotion ancestry control the operation.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `photo` | [InputFile](inputfile.md) | Yes | This contains the photo sizes or photo source for the object. |

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
