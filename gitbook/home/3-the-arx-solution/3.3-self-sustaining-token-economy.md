# 3.3 Self-Sustaining Token Economy

{% hint style="info" %}
This page describes the planned token economy. It is not live. The token contracts are currently deployed on the Sepolia testnet; see [Architecture](../../usdarx/architecture.md).
{% endhint %}

The ARX ecosystem is designed around a utility token that links all network participants through shared economic incentives. The token is intended to underpin **payments**, **staking**, **governance**, and **infrastructure rewards**.

### Token Utility

The token is designed to serve distinct roles for different participants within the network:

* **Users:** Spend tokens to access premium features, such as VPN and eSIM services, or to facilitate peer-to-peer payments and microtransactions.
* **Validators and Relays:** Stake tokens to secure the network, and earn rewards proportional to their reliability, uptime, and contribution to network privacy.
* **Developers and Merchants:** Integrate ARX infrastructure into their own platforms and receive ecosystem incentives for maintaining high-quality applications or payment gateways.

---

### The Economic Cycle

ARX is designed as a **closed economic loop** where value is generated by the utility and health of the network rather than the extraction of user data.

{% hint style="success" %}
**Value-Driven Privacy**
By avoiding reliance on advertising or data sales, the model aims to make privacy and stability **measurable, rewarded outcomes** of the network's operation rather than "costs".
{% endhint %}

---

> [!IMPORTANT]
> This model is designed to align the interests of all stakeholders. When the network is secure and private, its utility increases, benefiting the entire ecosystem through a transparent and sustainable economic framework.
