# RichInlineMath

An inline mathematical expression.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | string | Yes | The mathematical expression to render. |
| `type` | `"math"` | Yes | The rich content node type is math. |
