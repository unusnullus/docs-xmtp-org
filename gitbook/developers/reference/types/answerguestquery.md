# AnswerGuestQuery

The single inline result to answer a query issued to your bot. Unsupported content is rejected before accepting an answer.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `result` | [InlineResult](inlineresult.md) | Yes | The inline result to deliver for this query. |

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
