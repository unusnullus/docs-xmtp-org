# 8.3 Proof-of-Relay Rewards Distribution

Proof-of-Relay (PoR) aligns economic rewards with actual performance. Nodes that provide bandwidth, message routing, or relay services are compensated according to verified contribution metrics.

### Reward mechanism

1. Nodes submit verifiable data on latency, uptime, and message throughput.
2. Validator committees aggregate and validate reports.
3. Smart contracts automatically calculate and distribute rewards.

### Reward structure

| **Role**        | **Reward Share (Indicative)**   | **Source of Rewards**               | **Function**                                                                                                                              | **Optional Service Modules**                                         |
| --------------- | ------------------------------- | ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| Relay Node      | 30–40%                          | Proof-of-Relay metrics              | Handle encrypted data routing and VPN/eSIM relay tasks. Performance-based rewards tied to bandwidth, uptime, and latency.                 | VPN relay, eSIM routing, bandwidth provisioning                      |
| Storage Node    | 10–15%                          | Proof-of-Storage metrics            | Host encrypted user files and decentralized cloud storage. Rewards distributed based on uptime, available storage, and retrieval success. | Cloud storage, backup redundancy                                     |
| Validators      | 25–30%                          | Proof-of-Stake and relay validation | Validate transactions, verify relay metrics, and secure consensus. Form the governance backbone of the network.                           | Can operate with or without additional service modules (VPN/storage) |
| Block Producers | Subset of validators (bonus 5%) | Consensus priority                  | Finalize blocks, maintain state integrity, and record verified relay/storage metrics.                                                     | Can also serve as relay or storage nodes for extra rewards           |
| Delegators      | 10–15%                          | Validator reward share              | Support network security by staking through validators. Earn proportional rewards without operating infrastructure.                       | N/A                                                                  |
| DAO Reserve     | 5%                              | Treasury allocation                 | Used for audits, bounties, liquidity support, and ecosystem sustainability.                                                               | N/A                                                                  |

### Penalty rules

Nodes with consistent downtime or failed verifications lose part of their stake (0.5–2%) depending on severity.  This discourages negligence and keeps performance metrics high.

This PoR structure ensures measurable fairness, transparency, and efficiency in distributing ecosystem value.
