# InputDraftRichInlineMention

An account handle mention within rich text. Use this node in a temporary rich draft.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [InputDraftRichText](inputdraftrichtext.md) | Yes | The handle displayed as an account mention. |
| `type` | `"mention"` | Yes | The rich content node type is mention. |
