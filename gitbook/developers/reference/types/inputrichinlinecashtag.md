# InputRichInlineCashtag

A cashtag displayed within rich text. Use this node when sending rich content.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [InputRichText](inputrichtext.md) | Yes | The cashtag text, including its leading $. |
| `type` | `"cashtag"` | Yes | The rich content node type is cashtag. |
