# InputRichInlineBankCard

A bank card number displayed within rich text. Use this node when sending rich content.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | string | Yes | The bank card number displayed in this inline node. |
| `type` | `"bank_card"` | Yes | The rich content node type is bank_card. |
