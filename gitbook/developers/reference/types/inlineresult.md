# InlineResult

One result supplied by your bot. Media belong to your bot or use an importable HTTPS URL.

Supply exactly one of the following forms. Required fields apply within each form.

- When `type` is `"article"`, use [InlineResultArticle](inlineresultarticle.md).

- When `type` is `"photo"`, use [InlineResultPhoto](inlineresultphoto.md).

- When `type` is `"animation"`, use [InlineResultAnimation](inlineresultanimation.md).

- When `type` is `"video"`, use [InlineResultVideo](inlineresultvideo.md).

- When `type` is `"audio"`, use [InlineResultAudio](inlineresultaudio.md).

- When `type` is `"voice"`, use [InlineResultVoice](inlineresultvoice.md).

- When `type` is `"document"`, use [InlineResultDocument](inlineresultdocument.md).

- When `type` is `"location"`, use [InlineResultLocation](inlineresultlocation.md).

- When `type` is `"venue"`, use [InlineResultVenue](inlineresultvenue.md).

- When `type` is `"contact"`, use [InlineResultContact](inlineresultcontact.md).

- When `type` is `"game"`, use [InlineResultGame](inlineresultgame.md).

- When `type` is `"sticker"`, use [InlineResultSticker](inlineresultsticker.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
