# RichInlineMention

An account handle mention within rich text.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [RichText](richtext.md) | Yes | The handle displayed as an account mention. |
| `type` | `"mention"` | Yes | The rich content node type is mention. |
