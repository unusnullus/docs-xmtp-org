# IncomingMessagesDeleted

A private payload or a group payload selected by chat.kind. This type grants no access.

You receive one of the following forms. Required fields apply within each form.

- GroupMessagesDeleted describes a public group payload: [GroupMessagesDeleted](groupmessagesdeleted.md).

- The messages reported as deleted from one chat: [MessagesDeleted](messagesdeleted.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
