# RichButtonLabelPart

A text or date and time part within a rich button label. You can nest plain text and date_time label segments to a depth of 3. The complete button label must contain 1 to 64 UTF-16 code units.

You receive one of the following forms. Required fields apply within each form.

- The value has the type string.

- `type` is `"date_time"`: [RichButtonDateTime](richbuttondatetime.md).

- The value has the type Array of [RichButtonLabelPart](richbuttonlabelpart.md).
