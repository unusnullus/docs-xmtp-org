# 12.3 Developer and ecosystem growth

Third-party developers can build bots for ARX Messenger on **Nexo**, the ARX bot platform. Developers run their own program and store its state. Nexo provides the Bot API and delivers the events the program needs to respond.

* **Nexo Bot API**: Create a bot through `@NEXOCREATOR` and receive updates by polling or at an HTTPS webhook.
* **SDKs**: Official clients for **TypeScript**, **Python**, and **Rust**, with complete example programs in all three languages.
* **What bots can do today**: Work in private chats with users. Bots can send text and media, process files, collect answers with buttons and polls, share locations and contacts, and show a draft while they prepare a reply.
* **Ecosystem grants**: DAO-funded initiatives supporting infrastructure tools and regional adoption.

{% hint style="warning" %}
**Not available yet**
Mini Apps, inline mode, and games are not available. Payments, paid content, and paid broadcasts are not available. Bots cannot take part in group or channel conversations. The developer docs list every current limitation.
{% endhint %}

{% hint style="info" %}
**Privacy in bot chats**
Bot chats are not end-to-end encrypted. ARX processes their content, and the bot's developer can read and store what users send to the bot. A bot cannot read a user's other conversations.
{% endhint %}
