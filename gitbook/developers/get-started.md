# Get started

* [Quickstart](quickstart.md): Create a Nexo bot and send its first reply with any of the three SDKs.
* [Testing](testing.md): Test your handlers locally, then verify your bot in Messenger.
* [SDKs and CLI](sdks.md): Install the TypeScript, Python or Rust SDK and use the development CLI.
* [MCP server for AI agents](mcp.md): Connect Claude Code, Claude Desktop, Cursor, VS Code or any MCP client to the ARX Nexo MCP server and let your agent build, configure and test your bot.
* [Environments](environments.md): Move a program you tested with a TESTBOT to a regular bot.
