# PaymentPlan

A one-time or manually renewed recurring payment plan.

You receive one of the following forms. Required fields apply within each form.

- `kind` is `"one_time"`: [PaymentOneTimePlan](paymentonetimeplan.md).

- `kind` is `"recurring"`: [PaymentRecurringPlan](paymentrecurringplan.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
