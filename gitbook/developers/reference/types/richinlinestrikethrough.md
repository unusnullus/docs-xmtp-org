# RichInlineStrikethrough

Inline text displayed with a strikethrough.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [RichText](richtext.md) | Yes | The inline text displayed with a strikethrough. |
| `type` | `"strikethrough"` | Yes | The rich content node type is strikethrough. |
