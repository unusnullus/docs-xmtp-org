# GuestDisclosedContent

Caller-disclosed text and entities. Attachments are unavailable on this Guest producer.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `entities` | Array of [Entity](entity.md) | Yes | Formatting of the disclosed text. |
| `text` | string | Yes | The text disclosed by the caller, unverified by the server. |
