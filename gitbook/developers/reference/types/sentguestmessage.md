# SentGuestMessage

The inline message reference returned after accepting one Guest answer. This reference does not confirm delivery to another device.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `inline_message_id` | string | Yes | Use this reference for operations on the interactive message. The minimum length is 1 character. The maximum length is 512 characters. |

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
