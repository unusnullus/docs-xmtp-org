# InputRichInlineSuperscript

Inline text displayed as a superscript. Use this node when sending rich content.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [InputRichText](inputrichtext.md) | Yes | The inline text displayed as a superscript. |
| `type` | `"superscript"` | Yes | The rich content node type is superscript. |

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
