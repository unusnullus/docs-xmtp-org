# TopicClosedService

A group forum service reporting topic_closed. The enclosing message identifies the existing topic; this event does not grant topic access.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `type` | `"topic_closed"` | Yes | The service event type is topic_closed. |
