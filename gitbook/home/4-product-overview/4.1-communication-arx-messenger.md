# 4.1 Communication – ARX Messenger

ARX Messenger is the core of the ecosystem and the main user interface. It enables private, secure, and censorship-resistant communication for individuals and communities.

**Core features**:

* **End-to-end encryption**: All messages use X3DH and Double Ratchet encryption. Only sender and recipient can decrypt content.
* **Metadata protection**: Relays handle encrypted payloads without visibility into sender, receiver, or timestamps.
* **Wallet-based login**: No phone numbers or emails. Identity is cryptographic, verified through the wallet.
* **Groups and channels**: Create private or public communities with flexible moderation and access control.
* **Bots and mini-apps**: Automate tasks, run DAOs, or trigger blockchain transactions directly from chat.
* **Ephemeral messages**: Optional disappearing messages and encrypted attachments enhance privacy.
* **Offline relay tolerance**: Distributed mailboxes allow reliable message delivery without central servers.

ARX Messenger serves as the unified interface for all ecosystem interactions. Users can communicate, initiate transactions, and access decentralized services directly within the chat environment. By combining privacy, flexibility, and blockchain connectivity, ARX Messenger bridges communication with financial and network functions under a single encrypted interface.
