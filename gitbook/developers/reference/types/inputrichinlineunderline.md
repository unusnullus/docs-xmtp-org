# InputRichInlineUnderline

Underlined inline text. Use this node when sending rich content.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [InputRichText](inputrichtext.md) | Yes | The underlined inline text. |
| `type` | `"underline"` | Yes | The rich content node type is underline. |

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
