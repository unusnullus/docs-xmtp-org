# RichFooter

A footer text block within rich content.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [RichText](richtext.md) | Yes | The footer text displayed below the preceding rich content. |
| `type` | `"footer"` | Yes | The rich content node type is footer. |
