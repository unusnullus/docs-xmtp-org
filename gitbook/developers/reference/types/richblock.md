# RichBlock

One supported rich content block.

You receive one of the following forms. Required fields apply within each form.

- `type` is `"heading"`: [RichHeading](richheading.md).

- `type` is `"paragraph"`: [RichParagraph](richparagraph.md).

- `type` is `"footer"`: [RichFooter](richfooter.md).

- `type` is `"divider"`: [RichDivider](richdivider.md).

- `type` is `"preformatted"`: [RichPreformatted](richpreformatted.md).

- `type` is `"math"`: [RichMath](richmath.md).

- `type` is `"blockquote"`: [RichBlockquote](richblockquote.md).

- `type` is `"expandable_blockquote"`: [RichExpandableBlockquote](richexpandableblockquote.md).

- `type` is `"pull_quote"`: [RichPullQuote](richpullquote.md).

- `type` is `"details"`: [RichDetails](richdetails.md).

- `type` is `"reference"`: [RichReference](richreference.md).

- `type` is `"anchor"`: [RichAnchor](richanchor.md).

- `type` is `"list"`: [RichList](richlist.md).

- `type` is `"table"`: [RichTable](richtable.md).

- `type` is `"photo"`: [RichPhoto](richphoto.md).

- `type` is `"video"`: [RichVideo](richvideo.md).

- `type` is `"animation"`: [RichAnimation](richanimation.md).

- `type` is `"audio"`: [RichAudio](richaudio.md).

- `type` is `"voice"`: [RichVoice](richvoice.md).

- `type` is `"document"`: [RichDocument](richdocument.md).

- `type` is `"collage"`: [RichCollage](richcollage.md).

- `type` is `"slideshow"`: [RichSlideshow](richslideshow.md).

- `type` is `"map"`: [RichMap](richmap.md).

- `type` is `"buttons"`: [RichButtons](richbuttons.md).
