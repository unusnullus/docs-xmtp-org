# InlineCachedFile

An existing file available to your bot.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `file_id` | string | Yes | Your bot can use this opaque identifier to send or retrieve the file. The minimum length is 1 character. The maximum length is 2,048 characters. |
