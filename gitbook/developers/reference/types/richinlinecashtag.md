# RichInlineCashtag

A cashtag displayed within rich text.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [RichText](richtext.md) | Yes | The cashtag text, including its leading $. |
| `type` | `"cashtag"` | Yes | The rich content node type is cashtag. |
