# GuestMessage

An accepted Nexo group original or a client-asserted E2E disclosure. Neither grants membership, history or future updates.

You receive one of the following forms. Required fields apply within each form.

- `is_ephemeral` is `false`, `is_from_offline` is `false`, and `kind` is `"content"`: [NexoGuestMessage](nexoguestmessage.md).

- `is_from_offline` is `false`: [E2eGuestMessage](e2eguestmessage.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
