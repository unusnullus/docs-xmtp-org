# RichInlineBotCommand

A bot command displayed within rich text.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [RichText](richtext.md) | Yes | The bot command text, including its leading slash. |
| `type` | `"bot_command"` | Yes | The rich content node type is bot_command. |
