# 8.1 Circular Economy Design

ARX connects all participants through a continuous value cycle that transforms activity into revenue and reliability into reward.

**Value flow**:

1. Users pay for services such as VPN sessions, eSIM data, and Pro subscriptions using ARX or supported stablecoins.
2. Validators and relay nodes ensure uptime and service quality, earning proportional rewards.
3. Merchants and developers integrate ARX payments or identity features, generating transaction fees.
4. The DAO Treasury collects network fees, funds validator rewards, growth initiatives, and performs buybacks when approved through governance.

**Simplified loop**:\
Users → Pay Fees → DAO Treasury → Rewards → Improved Network → More Users

This model ensures every transaction contributes to the network’s stability and growth.
