# RichHeading

A rich heading at the selected size.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `size` | integer | Yes | Set the heading level from 1 through 6. |
| `text` | [RichText](richtext.md) | Yes | The heading text at the selected heading size. |
| `type` | `"heading"` | Yes | The rich content node type is heading. |
