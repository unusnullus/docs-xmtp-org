# TopicsCreate

Create a named private or group forum topic.

Supply at least one of the following forms. Required fields apply within each form.

- Create a private topic with a required name and optional icon: [PrivateTopicCreate](privatetopiccreate.md).

- Create a named topic in a group with forums enabled: [GroupForumCreate](groupforumcreate.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
