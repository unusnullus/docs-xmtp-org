# InputDraftRichInlineHashtag

A hashtag displayed within rich text. Use this node in a temporary rich draft.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [InputDraftRichText](inputdraftrichtext.md) | Yes | The hashtag text, including its leading #. |
| `type` | `"hashtag"` | Yes | The rich content node type is hashtag. |
