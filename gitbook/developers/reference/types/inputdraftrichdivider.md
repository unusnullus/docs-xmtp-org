# InputDraftRichDivider

A horizontal divider between rich content blocks. Use this node in a temporary rich draft.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `type` | `"divider"` | Yes | The rich content node type is divider. |
