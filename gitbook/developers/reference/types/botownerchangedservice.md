# BotOwnerChangedService

A service event reporting that the bot owner changed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `bot` | [User](user.md) | Yes | This identifies the bot whose ownership changed. |
| `type` | `"bot_owner_changed"` | Yes | The service event type is bot_owner_changed. |
