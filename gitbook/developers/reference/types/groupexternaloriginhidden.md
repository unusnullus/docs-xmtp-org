# GroupExternalOriginHidden

The original time without a private source or author identifier. It is not a synthetic user or a read grant.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `sent_at` | string | Yes | This records when the message was sent, in RFC 3339 format. The format is `date-time`. |
| `type` | `"hidden_user"` | Yes | The service or update type selecting this payload. |
