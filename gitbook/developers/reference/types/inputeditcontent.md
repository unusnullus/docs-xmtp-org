# InputEditContent

Replacement message content accepted by messages.edit.

Supply exactly one of the following forms. Required fields apply within each form.

- When `type` is `"photo"`, use [InputPhoto](inputphoto.md).

- When `type` is `"video"`, use [InputVideo](inputvideo.md).

- When `type` is `"animation"`, use [InputAnimation](inputanimation.md).

- When `type` is `"audio"`, use [InputAudio](inputaudio.md).

- When `type` is `"voice"`, use [InputVoice](inputvoice.md).

- When `type` is `"video_note"`, use [InputVideoNote](inputvideonote.md).

- When `type` is `"document"`, use [InputDocument](inputdocument.md).

- When `type` is `"text"`, use [InputText](inputtext.md).

- When `type` is `"dice"`, use [InputDice](inputdice.md).

- When `type` is `"rich"`, use [InputRich](inputrich.md).

- When `type` is `"live_photo"`, use [InputLivePhoto](inputlivephoto.md).

- When `type` is `"checklist"`, use [InputChecklistContent](inputchecklistcontent.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
