# RichParagraph

A paragraph of inline rich text.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [RichText](richtext.md) | Yes | The paragraph's inline text, in reading order. |
| `type` | `"paragraph"` | Yes | The rich content node type is paragraph. |
