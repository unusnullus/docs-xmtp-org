# InputDraftRichInlineSpoiler

Inline text concealed until the user reveals it. Use this node in a temporary rich draft.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [InputDraftRichText](inputdraftrichtext.md) | Yes | The inline text concealed until the user reveals it. |
| `type` | `"spoiler"` | Yes | The rich content node type is spoiler. |
