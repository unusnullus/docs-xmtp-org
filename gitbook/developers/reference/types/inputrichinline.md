# InputRichInline

One supported inline text node. Use this node when sending rich content.

Supply exactly one of the following forms. Required fields apply within each form.

- When `type` is `"bold"`, use [InputRichInlineBold](inputrichinlinebold.md).

- When `type` is `"italic"`, use [InputRichInlineItalic](inputrichinlineitalic.md).

- When `type` is `"underline"`, use [InputRichInlineUnderline](inputrichinlineunderline.md).

- When `type` is `"strikethrough"`, use [InputRichInlineStrikethrough](inputrichinlinestrikethrough.md).

- When `type` is `"spoiler"`, use [InputRichInlineSpoiler](inputrichinlinespoiler.md).

- When `type` is `"marked"`, use [InputRichInlineMarked](inputrichinlinemarked.md).

- When `type` is `"subscript"`, use [InputRichInlineSubscript](inputrichinlinesubscript.md).

- When `type` is `"superscript"`, use [InputRichInlineSuperscript](inputrichinlinesuperscript.md).

- When `type` is `"code"`, use [InputRichInlineCode](inputrichinlinecode.md).

- When `type` is `"math"`, use [InputRichInlineMath](inputrichinlinemath.md).

- When `type` is `"email"`, use [InputRichInlineEmail](inputrichinlineemail.md).

- When `type` is `"phone"`, use [InputRichInlinePhone](inputrichinlinephone.md).

- When `type` is `"bank_card"`, use [InputRichInlineBankCard](inputrichinlinebankcard.md).

- When `type` is `"mention"`, use [InputRichInlineMention](inputrichinlinemention.md).

- When `type` is `"hashtag"`, use [InputRichInlineHashtag](inputrichinlinehashtag.md).

- When `type` is `"cashtag"`, use [InputRichInlineCashtag](inputrichinlinecashtag.md).

- When `type` is `"bot_command"`, use [InputRichInlineBotCommand](inputrichinlinebotcommand.md).

- When `type` is `"url"`, use [InputRichInlineUrl](inputrichinlineurl.md).

- When `type` is `"text_mention"`, use [InputRichInlineTextMention](inputrichinlinetextmention.md).

- When `type` is `"date_time"`, use [InputRichInlineDateTime](inputrichinlinedatetime.md).

- When `type` is `"anchor_link"`, use [InputRichInlineAnchorLink](inputrichinlineanchorlink.md).

- When `type` is `"reference_link"`, use [InputRichInlineReferenceLink](inputrichinlinereferencelink.md).

- When `type` is `"anchor"`, use [InputRichInlineAnchor](inputrichinlineanchor.md).

- When `type` is `"button"`, use [InputRichInlineButton](inputrichinlinebutton.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
