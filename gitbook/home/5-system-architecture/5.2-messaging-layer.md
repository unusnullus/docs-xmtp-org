# 5.2 Messaging layer

The messaging layer delivers private, real-time communication between users without reliance on central servers.\
All message content and metadata remain encrypted from the sender to the recipient.

Core functions:

* **Encrypted payloads**: Messages and files are encrypted locally and never stored on-chain.
* **Relay nodes**: Independent relays transport encrypted data without accessing content or metadata.
* **Mailbox architecture**: Ensures message delivery even when users are offline by using temporary encrypted storage.
* **Smart interactions**: Chats can include commands for payments, contract triggers, or DAO actions executed directly through the wallet.

This design provides secure and flexible communication while maintaining complete decentralization.
