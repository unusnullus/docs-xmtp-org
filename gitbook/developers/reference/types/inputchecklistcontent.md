# InputChecklistContent

The checklist content to send in a new message.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `checklist` | [InputChecklist](inputchecklist.md) | Yes | This contains the checklist title, tasks, and collaboration settings. |
| `type` | `"checklist"` | Yes | The content type is checklist. |
