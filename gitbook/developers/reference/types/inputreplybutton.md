# InputReplyButton

A reply keyboard button that sends text or requests information from the user.

Supply exactly one of the following forms. Required fields apply within each form.

- When `type` is `"text"`, use [InputReplyButtonText](inputreplybuttontext.md).

- When `type` is `"request_users"`, use [InputReplyButtonRequestUsers](inputreplybuttonrequestusers.md).

- When `type` is `"request_contact"`, use [InputReplyButtonRequestContact](inputreplybuttonrequestcontact.md).

- When `type` is `"request_location"`, use [InputReplyButtonRequestLocation](inputreplybuttonrequestlocation.md).

- When `type` is `"request_poll"`, use [InputReplyButtonRequestPoll](inputreplybuttonrequestpoll.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
