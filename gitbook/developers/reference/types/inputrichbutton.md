# InputRichButton

An interactive button embedded in rich content. Use this node when sending rich content.

Supply exactly one of the following forms. Required fields apply within each form.

- When `type` is `"callback"`, use [InputRichInlineButtonCallback](inputrichinlinebuttoncallback.md).

- When `type` is `"url"`, use [InputRichInlineButtonUrl](inputrichinlinebuttonurl.md).

- When `type` is `"copy_text"`, use [InputRichInlineButtonCopyText](inputrichinlinebuttoncopytext.md).

- When `type` is `"disabled"`, use [InputRichInlineButtonDisabled](inputrichinlinebuttondisabled.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
