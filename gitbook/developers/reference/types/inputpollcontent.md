# InputPollContent

The poll content to send in a new message.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `poll` | [InputPoll](inputpoll.md) | Yes | This contains poll settings or the current poll state. |
| `type` | `"poll"` | Yes | The content type is poll. |

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
