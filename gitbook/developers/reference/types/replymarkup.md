# ReplyMarkup

A keyboard or reply input instruction to attach to a message.

Supply exactly one of the following forms. Required fields apply within each form.

- When `type` is `"inline_keyboard"`, use [InputInlineKeyboard](inputinlinekeyboard.md).

- When `type` is `"reply_keyboard"`, use [InputReplyKeyboard](inputreplykeyboard.md).

- When `type` is `"remove_keyboard"`, use [InputRemoveKeyboard](inputremovekeyboard.md).

- When `type` is `"force_reply"`, use [InputForceReply](inputforcereply.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
