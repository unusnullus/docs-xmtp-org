# 5.3 Network layer

The network layer supports ARX operations through a hybrid Proof-of-Stake (PoS) and Proof-of-Relay (PoR) mechanism. It ensures both consensus integrity and network reliability.

Main components:

* **Relay nodes**: Handle encrypted message routing, VPN traffic, and data transmission.
* **Validator nodes**: Produce blocks, confirm transactions, and verify relay performance.
* **Proof-of-Relay**: Rewards nodes based on measurable metrics such as uptime, latency, and throughput.
* **Slashing and penalties**: Nodes with poor performance or malicious behavior lose a portion of their stake.
* **Interoperability**: Supports EVM compatibility and cross-chain bridges for liquidity and governance alignment.

The network layer ensures that reliability and performance are directly rewarded through verifiable contribution.
