# 7.3 Utility and governance functionality

The ARX token serves as the foundation of all network activity, aligning user incentives with protocol security and growth.

### Utility functions

* **Payments and fees**: Used for transactions, subscriptions, VPN/eSIM access, and premium services.
* **Staking**: Validators and delegators lock ARX to secure the network and earn performance-based rewards.
* **Rewards and incentives**: Active users, developers, and node operators receive ARX for ecosystem contributions.
* **Governance**: Token holders propose and vote on protocol upgrades, treasury spending, and rule changes.

### Governance mechanics

* **Validators**: Run nodes, validate relays, and secure consensus.
* **Delegators**: Stake ARX through trusted validators to earn proportional rewards.
* **Block producers**: High-performance validators ensuring efficiency and finality.
* **Voting**: Weighted by stake, ensuring proportional influence and transparency.
* **Execution**: Approved proposals are automatically enacted through governance contracts.

Through this structure, ARX combines practical utility with decentralized decision-making. Token holders directly shape the network’s evolution while earning rewards for supporting its infrastructure.
