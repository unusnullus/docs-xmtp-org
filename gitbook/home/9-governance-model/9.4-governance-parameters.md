# 9.4 Governance parameters

ARX governance operates under clear and predefined parameters to maintain transparency, predictability, and accountability.

| **Parameter**               | **Description**                                          | **Default Value**    |
| --------------------------- | -------------------------------------------------------- | -------------------- |
| Proposal creation threshold | Minimum ARX stake required to submit a proposal          | 10,000 ARX           |
| Voting duration             | Time period during which votes are accepted              | 7 days               |
| Quorum requirement          | Minimum participation rate for a valid vote              | 20% of staked supply |
| Approval threshold          | Minimum affirmative votes required for proposal approval | 60% of votes cast    |
| Execution delay             | Time between proposal approval and on-chain execution    | 48 hours             |
| Delegation support          | Allows token holders to delegate votes                   | Enabled              |

These rules prevent spam, ensure fair representation, and maintain governance reliability. All parameters can be modified only through DAO proposals, allowing the governance system to evolve alongside the network.
