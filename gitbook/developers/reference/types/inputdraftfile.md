# InputDraftFile

An existing file available to your bot for use in a draft. Drafts cannot upload files or import URLs.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `file_id` | string | Yes | Use an existing file ID available to your bot. Drafts cannot upload files or import URLs. The minimum length is 1 character. The maximum length is 2,048 characters. |
