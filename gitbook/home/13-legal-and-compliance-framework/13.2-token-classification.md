# 13.2 Token Classification

After internal and external legal reviews, the ARX token is classified as a utility token under Swiss law. It does not represent equity, debt, or ownership in any legal entity. Instead, it grants access to specific network functions such as staking, governance, and payment for services.

### Classification rationale

* The token is used to access ARX network features, including communication services, VPN/eSIM, and premium subscriptions.
* It is not marketed or structured as an investment product.
* Token value is derived from network utility and demand, not speculative profit expectations.

Under the **EU MiCA framework**, ARX qualifies as an **“Other Crypto-Asset”** (OCA), not an e-money token (EMT) or asset-referenced token (ART). This classification ensures compliance with MiCA disclosure requirements while maintaining operational flexibility.
