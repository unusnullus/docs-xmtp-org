# GroupSetCustomTitle

Arguments for members.set_custom_title in Super Groups with group moderation enabled. Current membership, permissions and promotion ancestry control the operation.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `custom_title` | string | Yes | The administrator's displayed title, up to 16 characters. |
