# ProfileText

One set of profile text fields, used for the default profile or a localization.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `description` | string or null | Yes | This is the profile description for your bot. The limit is 512 UTF-16 code units. |
| `name` | string or null | Yes | This is the display name of the user, bot, contact, or provider. The limit is 64 UTF-16 code units. |
| `short_description` | string or null | Yes | This is the short profile description displayed for your bot. The limit is 120 UTF-16 code units. |
