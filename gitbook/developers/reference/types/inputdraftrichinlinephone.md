# InputDraftRichInlinePhone

A telephone link within rich text. Use this node in a temporary rich draft.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | string | Yes | The telephone number displayed as a phone link. |
| `type` | `"phone"` | Yes | The rich content node type is phone. |

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
