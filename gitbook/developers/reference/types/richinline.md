- `type` is `"italic"`: [RichInlineItalic](richinlineitalic.md).

- `type` is `"underline"`: [RichInlineUnderline](richinlineunderline.md).

- `type` is `"spoiler"`: [RichInlineSpoiler](richinlinespoiler.md).

- `type` is `"marked"`: [RichInlineMarked](richinlinemarked.md).

- `type` is `"subscript"`: [RichInlineSubscript](richinlinesubscript.md).

- `type` is `"superscript"`: [RichInlineSuperscript](richinlinesuperscript.md).

- `type` is `"code"`: [RichInlineCode](richinlinecode.md).

- `type` is `"math"`: [RichInlineMath](richinlinemath.md).

- `type` is `"email"`: [RichInlineEmail](richinlineemail.md).

- `type` is `"phone"`: [RichInlinePhone](richinlinephone.md).

- `type` is `"bank_card"`: [RichInlineBankCard](richinlinebankcard.md).

- `type` is `"mention"`: [RichInlineMention](richinlinemention.md).

- `type` is `"hashtag"`: [RichInlineHashtag](richinlinehashtag.md).

- `type` is `"reference_link"`: [RichInlineReferenceLink](richinlinereferencelink.md).

- `type` is `"anchor"`: [RichInlineAnchor](richinlineanchor.md).

- `type` is `"button"`: [RichInlineButton](richinlinebutton.md).
