# Entity

A formatting entity in received text. Its type selects how the UTF-16 text span is displayed.

You receive one of the following forms. Required fields apply within each form.

- `type` is `"mention"`: [EntityMention](entitymention.md).

- `type` is `"hashtag"`: [EntityHashtag](entityhashtag.md).

- `type` is `"cashtag"`: [EntityCashtag](entitycashtag.md).

- `type` is `"bot_command"`: [EntityBotCommand](entitybotcommand.md).

- `type` is `"url"`: [EntityUrl](entityurl.md).

- `type` is `"email"`: [EntityEmail](entityemail.md).

- `type` is `"phone_number"`: [EntityPhoneNumber](entityphonenumber.md).

- `type` is `"bold"`: [EntityBold](entitybold.md).

- `type` is `"italic"`: [EntityItalic](entityitalic.md).

- `type` is `"underline"`: [EntityUnderline](entityunderline.md).

- `type` is `"strikethrough"`: [EntityStrikethrough](entitystrikethrough.md).

- `type` is `"spoiler"`: [EntitySpoiler](entityspoiler.md).

- `type` is `"code"`: [EntityCode](entitycode.md).

- `type` is `"pre"`: [EntityPre](entitypre.md).

- `type` is `"blockquote"`: [EntityBlockquote](entityblockquote.md).

- `type` is `"expandable_blockquote"`: [EntityExpandableBlockquote](entityexpandableblockquote.md).

- `type` is `"text_link"`: [EntityTextLink](entitytextlink.md).

- `type` is `"text_mention"`: [EntityTextMention](entitytextmention.md).

- `type` is `"date_time"`: [EntityDateTime](entitydatetime.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
