| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `dice` | [DiceValue](dicevalue.md) | Yes | This contains the dice emoji and its generated random result. |
| `type` | `"dice"` | Yes | The content type is dice. |
