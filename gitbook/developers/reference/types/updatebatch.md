# UpdateBatch

The ordered updates returned by a polling request.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `updates` | Array of [Update](update.md) | Yes | These are the updates in the polling response, in delivery order. The maximum is 100 items. |
