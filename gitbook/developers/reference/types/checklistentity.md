# ChecklistEntity

A supported formatting entity within checklist text. Offsets and lengths use UTF-16 code units.

You receive one of the following forms. Required fields apply within each form.

- `type` is `"bold"`: [EntityBold](entitybold.md).

- `type` is `"italic"`: [EntityItalic](entityitalic.md).

- `type` is `"underline"`: [EntityUnderline](entityunderline.md).

- `type` is `"strikethrough"`: [EntityStrikethrough](entitystrikethrough.md).

- `type` is `"spoiler"`: [EntitySpoiler](entityspoiler.md).

- `type` is `"date_time"`: [EntityDateTime](entitydatetime.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
