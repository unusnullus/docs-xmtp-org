# 5.6 Scalability and performance

ARX is designed to serve millions of users while preserving decentralization.\
The architecture achieves high throughput through parallel processing and off-chain operations.

Performance mechanisms:

* **Off-chain communication**: Most activity occurs off-chain to reduce blockchain congestion.
* **Relay zoning**: Regional relay clusters minimize latency and optimize message delivery.
* **Meta-transactions**: Users can interact with the blockchain without holding native gas tokens.
* **Parallel routing**: Routing and validation occur simultaneously for maximum efficiency.
* **Real-time monitoring**: System metrics ensure node performance and responsiveness.

This configuration provides near real-time user experience with decentralized architecture.
