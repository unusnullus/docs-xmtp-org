# RichCaption

The text and optional credit associated with rich media.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `credit` | [RichText](richtext.md) | No | This is the attribution displayed with the quotation or media. |
| `text` | [RichText](richtext.md) | Yes | The caption text displayed with this rich media item. |

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
