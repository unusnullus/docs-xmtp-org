# InputDice

The dice emoji to send. ARX generates the result.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `emoji` | `"🎲"` or `"🎯"` or `"🎳"` or `"🏀"` or `"⚽"` or `"🎰"` | No | This is the emoji used for the reaction, dice, or effect. The default is `"🎲"`. |
| `type` | `"dice"` | Yes | The content type is dice. |

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
