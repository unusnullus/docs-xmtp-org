# RichInlineHashtag

A hashtag displayed within rich text.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [RichText](richtext.md) | Yes | The hashtag text, including its leading #. |
| `type` | `"hashtag"` | Yes | The rich content node type is hashtag. |
