# Content

The content of a received message. Its type field identifies the content variant.

You receive one of the following forms. Required fields apply within each form.

- `type` is `"photo"`: [PhotoContent](photocontent.md).

- `type` is `"video"`: [Video](video.md).

- `type` is `"animation"`: [Animation](animation.md).

- `type` is `"audio"`: [Audio](audio.md).

- `type` is `"voice"`: [Voice](voice.md).

- `type` is `"video_note"`: [VideoNote](videonote.md).

- `type` is `"document"`: [Document](document.md).

- `type` is `"text"`: [Text](text.md).

- `type` is `"dice"`: [Dice](dice.md).

- `type` is `"rich"`: [Rich](rich.md).

- `type` is `"live_photo"`: [LivePhoto](livephoto.md).

- `type` is `"poll"`: [PollContent](pollcontent.md).

- `type` is `"checklist"`: [ChecklistContent](checklistcontent.md).

- `type` is `"location"`: [LocationContent](locationcontent.md).

- `type` is `"venue"`: [VenueContent](venuecontent.md).

- `type` is `"contact"`: [ContactContent](contactcontent.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
