# InputDraftRichFooter

A footer text block within rich content. Use this node in a temporary rich draft.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [InputDraftRichText](inputdraftrichtext.md) | Yes | The footer text displayed below the preceding rich content. |
| `type` | `"footer"` | Yes | The rich content node type is footer. |
