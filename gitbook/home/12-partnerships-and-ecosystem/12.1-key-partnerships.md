# 12.1 Key partnerships

| **Partner / Category**                                | **Function**             | **Description**                                                                            |
| ----------------------------------------------------- | ------------------------ | ------------------------------------------------------------------------------------------ |
| **XMTP + Signal**                                     | Communication protocol   | Enables wallet-based identity and cross-app messaging interoperability.                    |
| **Card issuer (confidential)**                        | Financial infrastructure | Provides the fiat bridge and issuance of ARX crypto cards for global spending.             |
| **1GLOBAL**                                           | eSIM / Telecom           | Expands decentralized connectivity and mobile data access for VPN and eSIM users.          |
| **Infrastructure providers (e.g. Everstake Capital)** | Node reliability         | Support for validator hosting, relay node scaling, and distributed performance monitoring. |
| **Halborn**                                           | Compliance               | Independent audits of contracts, encryption, and network integrity.                        |

These partners form the backbone of ARX’s communication, payments, and connectivity layers, ensuring functionality and compliance from day one.
