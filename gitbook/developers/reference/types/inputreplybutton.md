# InputReplyButton

A reply keyboard button that sends text or requests information from the user.

You receive one of the following forms. Required fields apply within each form.

- `type` is `"text"`: [InputReplyButtonText](inputreplybuttontext.md).

- `type` is `"request_users"`: [InputReplyButtonRequestUsers](inputreplybuttonrequestusers.md).

- `type` is `"request_managed_bot"`: [InputReplyButtonRequestManagedBot](inputreplybuttonrequestmanagedbot.md).

- `type` is `"request_contact"`: [InputReplyButtonRequestContact](inputreplybuttonrequestcontact.md).

- `type` is `"request_location"`: [InputReplyButtonRequestLocation](inputreplybuttonrequestlocation.md).

- `type` is `"request_poll"`: [InputReplyButtonRequestPoll](inputreplybuttonrequestpoll.md).

- `type` is `"mini_app"`: [InputReplyButtonMiniApp](inputreplybuttonminiapp.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
