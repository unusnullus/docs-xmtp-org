# InputRichInlineMath

An inline mathematical expression. Use this node when sending rich content.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | string | Yes | The mathematical expression to render. |
| `type` | `"math"` | Yes | The rich content node type is math. |

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
