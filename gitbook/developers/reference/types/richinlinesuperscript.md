# RichInlineSuperscript

Inline text displayed as a superscript.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [RichText](richtext.md) | Yes | The inline text displayed as a superscript. |
| `type` | `"superscript"` | Yes | The rich content node type is superscript. |
