# RichInlineSubscript

Inline text displayed as a subscript.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [RichText](richtext.md) | Yes | The inline text displayed as a subscript. |
| `type` | `"subscript"` | Yes | The rich content node type is subscript. |
