# InputChecklistEntity

A supported formatting entity for checklist input. Offsets and lengths use UTF-16 code units.

Supply exactly one of the following forms. Required fields apply within each form.

- When `type` is `"bold"`, use [InputEntityBold](inputentitybold.md).

- When `type` is `"italic"`, use [InputEntityItalic](inputentityitalic.md).

- When `type` is `"underline"`, use [InputEntityUnderline](inputentityunderline.md).

- When `type` is `"strikethrough"`, use [InputEntityStrikethrough](inputentitystrikethrough.md).

- When `type` is `"spoiler"`, use [InputEntitySpoiler](inputentityspoiler.md).

- When `type` is `"date_time"`, use [InputEntityDateTime](inputentitydatetime.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
