# 12.3 Developer and ecosystem growth

Third-party developers can build bots for ARX Messenger on **Nexo**, the ARX bot platform. Developers run their own program and store its state. Nexo provides the Bot API and delivers the events the program needs to respond.

* **Nexo Bot API**: Create a bot through `@NEXOCREATOR` ([quickstart](../../developers/quickstart.md)) and receive updates by polling or at an HTTPS webhook.
* **SDKs**: Official [clients](../../developers/sdks.md) for **TypeScript**, **Python**, and **Rust**, with complete [example programs](../../developers/examples.md) in all three languages.
* **What bots can do today**: Converse in private chats with text, media, buttons, polls, locations, and contacts. Run [group bots](../../developers/groups.md) that answer commands, work in forum topics, and moderate members. Open [Mini Apps](../../developers/mini-apps.md) from a button or the menu. Sell access with crypto [invoices and subscriptions](../../developers/payments.md). In [advanced modes](../../developers/managed-bots.md), a bot can create bots for people or help them in their own chats.
* **AI agents**: An [MCP server](../../developers/mcp.md) lets an AI agent such as Claude Code or Cursor build, configure, and test a bot for you.
* **Ecosystem grants**: DAO-funded initiatives supporting infrastructure tools and regional adoption.

{% hint style="warning" %}
**Not available yet**
Inline mode and games are not available. Payments use crypto assets only, with no sandbox network, and paid media, paid broadcasts, and shipping are not available. In channels, bots can post text only. The [developer docs](../../developers/not-available-yet.md) list every current limitation.
{% endhint %}

{% hint style="info" %}
**Privacy in bot chats**
Chats with bots, and groups a bot has joined, are not end-to-end encrypted. ARX processes their content, and the bot's developer can read and store what users send to the bot. In a group with group privacy on, a bot receives only commands, mentions, and replies to its messages. A bot cannot read a user's other conversations unless the user shares them through a Business connection.
{% endhint %}
