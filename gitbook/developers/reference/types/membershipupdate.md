# MembershipUpdate

A change to your bot's membership in a private chat or a channel.

You receive one of the following forms. Required fields apply within each form.

- A private membership transition: [PrivateMemberUpdated](privatememberupdated.md).

- A change to your bot's membership in a channel: [ChannelMemberUpdated](channelmemberupdated.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
