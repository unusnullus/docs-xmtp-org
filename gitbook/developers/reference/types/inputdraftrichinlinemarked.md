# InputDraftRichInlineMarked

Highlighted inline text. Use this node in a temporary rich draft.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [InputDraftRichText](inputdraftrichtext.md) | Yes | The highlighted inline text. |
| `type` | `"marked"` | Yes | The rich content node type is marked. |
