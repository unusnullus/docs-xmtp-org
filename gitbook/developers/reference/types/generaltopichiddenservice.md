# GeneralTopicHiddenService

A group forum service reporting general_topic_hidden. The enclosing message identifies the existing topic; this event does not grant topic access.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `type` | `"general_topic_hidden"` | Yes | The service event type is general_topic_hidden. |
