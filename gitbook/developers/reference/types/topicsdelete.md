# TopicsDelete

Delete a private topic or a group forum topic, selected by the chat kind.

Supply at least one of the following forms. Required fields apply within each form.

- Retire the topic using its current metadata version: [PrivateTopicDelete](privatetopicdelete.md).

- Delete a group forum topic with DeleteMessages and a recoverable Idempotency-Key: [GroupForumDelete](groupforumdelete.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
