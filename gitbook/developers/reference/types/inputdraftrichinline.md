# InputDraftRichInline

One supported inline text node. Use this node in a temporary rich draft.

Supply exactly one of the following forms. Required fields apply within each form.

- When `type` is `"bold"`, use [InputDraftRichInlineBold](inputdraftrichinlinebold.md).

- When `type` is `"italic"`, use [InputDraftRichInlineItalic](inputdraftrichinlineitalic.md).

- When `type` is `"underline"`, use [InputDraftRichInlineUnderline](inputdraftrichinlineunderline.md).

- When `type` is `"strikethrough"`, use [InputDraftRichInlineStrikethrough](inputdraftrichinlinestrikethrough.md).

- When `type` is `"spoiler"`, use [InputDraftRichInlineSpoiler](inputdraftrichinlinespoiler.md).

- When `type` is `"marked"`, use [InputDraftRichInlineMarked](inputdraftrichinlinemarked.md).

- When `type` is `"subscript"`, use [InputDraftRichInlineSubscript](inputdraftrichinlinesubscript.md).

- When `type` is `"superscript"`, use [InputDraftRichInlineSuperscript](inputdraftrichinlinesuperscript.md).

- When `type` is `"code"`, use [InputDraftRichInlineCode](inputdraftrichinlinecode.md).

- When `type` is `"math"`, use [InputDraftRichInlineMath](inputdraftrichinlinemath.md).

- When `type` is `"email"`, use [InputDraftRichInlineEmail](inputdraftrichinlineemail.md).

- When `type` is `"phone"`, use [InputDraftRichInlinePhone](inputdraftrichinlinephone.md).

- When `type` is `"bank_card"`, use [InputDraftRichInlineBankCard](inputdraftrichinlinebankcard.md).

- When `type` is `"mention"`, use [InputDraftRichInlineMention](inputdraftrichinlinemention.md).

- When `type` is `"hashtag"`, use [InputDraftRichInlineHashtag](inputdraftrichinlinehashtag.md).

- When `type` is `"cashtag"`, use [InputDraftRichInlineCashtag](inputdraftrichinlinecashtag.md).

- When `type` is `"bot_command"`, use [InputDraftRichInlineBotCommand](inputdraftrichinlinebotcommand.md).

- When `type` is `"url"`, use [InputDraftRichInlineUrl](inputdraftrichinlineurl.md).

- When `type` is `"text_mention"`, use [InputDraftRichInlineTextMention](inputdraftrichinlinetextmention.md).

- When `type` is `"date_time"`, use [InputDraftRichInlineDateTime](inputdraftrichinlinedatetime.md).

- When `type` is `"anchor_link"`, use [InputDraftRichInlineAnchorLink](inputdraftrichinlineanchorlink.md).

- When `type` is `"reference_link"`, use [InputDraftRichInlineReferenceLink](inputdraftrichinlinereferencelink.md).

- When `type` is `"anchor"`, use [InputDraftRichInlineAnchor](inputdraftrichinlineanchor.md).

- When `type` is `"button"`, use [InputDraftRichInlineButton](inputdraftrichinlinebutton.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
