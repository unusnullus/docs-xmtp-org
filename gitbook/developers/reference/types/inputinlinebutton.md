# InputInlineButton

An inline button to attach to a message. Its type chooses its action.

You receive one of the following forms. Required fields apply within each form.

- `type` is `"callback"`: [InputInlineButtonCallback](inputinlinebuttoncallback.md).

- `type` is `"url"`: [InputInlineButtonUrl](inputinlinebuttonurl.md).

- `type` is `"copy_text"`: [InputInlineButtonCopyText](inputinlinebuttoncopytext.md).

- `type` is `"disabled"`: [InputInlineButtonDisabled](inputinlinebuttondisabled.md).

- `type` is `"mini_app"`: [InputInlineButtonMiniApp](inputinlinebuttonminiapp.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
