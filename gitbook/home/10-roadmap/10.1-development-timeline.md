# 10.1 Development Timeline

| **Date**     | **Milestone**                    | **Description**                                                                                                                |
| ------------ | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **2024**     | **MVP inception**                | Initial prototype with encrypted messenger, PoS chain selection, and early relay node testing.                                 |
| **Jan 2025** | **XMTP and Signal integration**  | Migration of messaging layer to XMTP, maintaining Signal’s X3DH and Double Ratchet encryption for metadata-free communication. |
| **May 2025** | **Wallet integration**           | Launch of multi-chain wallet inside the messenger with in-chat transfers, swaps, and on-ramp/off-ramp support.                 |
| **Sep 2025** | **App launch**                   | Public release of ARX with full “Speak, Pay, Connect” functionality uniting messaging, payments, and connectivity.             |
| **Dec 2025** | **Token Generation Event (TGE)** | Launch of the ARX token on mainnet with staking, delegation, and governance beta. Liquidity and community distribution begin.  |
| **Dec 2025** | **Crypto card**                  | Integration of global fiat bridge and premium metal cards, compliant with regional financial regulations.                      |
| **Jan 2026** | **VPN nodes activation**         | Validator-exposed VPN relays go live, creating a decentralized privacy network with performance-based rewards.                 |
| **Feb 2026** | **eSIM marketplace**             | Integration with 1Global for mobile data packages in 170+ countries, linked to ARX Pro plans.                                  |
| **Apr 2026** | **ARX Earn (ERC-4626)**          | Launch of yield vaults for stable assets such as USDC and USDT, generating on-chain passive income.                            |
| **May 2026** | **Mainnet launch**               | Network transitions to production with active validators, staking rewards, and Proof-of-Relay verification.                    |
| **Jun 2026** | **Staking vault**                | Introduction of the ARX staking vault for yield aggregation, delegation, and governance participation.                         |
| **Aug 2026** | **Pay-links and merchant SDK**   | Rollout of smart-contract payment links and merchant integrations for peer-to-peer and B2C transactions.                       |
| **Nov 2026** | **Group video and voice**        | Launch of encrypted group video calls with adaptive bandwidth and regional relay support.                                      |
| **Dec 2026** | **Bot SDK release**              | Developer SDK for bots and mini-apps enabling automation, DAO tooling, and Web3 integrations within the messenger.             |

Each milestone is executed under ARX’s core principles of security, progressive decentralization, and economic sustainability. This roadmap represents a practical and transparent plan for delivering a global, privacy-preserving communication and financial network.
