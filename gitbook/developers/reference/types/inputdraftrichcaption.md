# InputDraftRichCaption

The text and optional credit associated with rich media. Use this node in a temporary rich draft.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `credit` | [InputDraftRichText](inputdraftrichtext.md) | No | This is the attribution displayed with the quotation or media. |
| `text` | [InputDraftRichText](inputdraftrichtext.md) | Yes | The caption text displayed with this rich media item. |

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
