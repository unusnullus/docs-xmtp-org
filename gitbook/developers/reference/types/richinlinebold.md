Inline text displayed in bold.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [RichText](richtext.md) | Yes | The inline text displayed in bold. |
| `type` | `"bold"` | Yes | The rich content node type is bold. |
