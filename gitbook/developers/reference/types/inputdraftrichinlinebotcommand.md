# InputDraftRichInlineBotCommand

A bot command displayed within rich text. Use this node in a temporary rich draft.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [InputDraftRichText](inputdraftrichtext.md) | Yes | The bot command text, including its leading slash. |
| `type` | `"bot_command"` | Yes | The rich content node type is bot_command. |

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
