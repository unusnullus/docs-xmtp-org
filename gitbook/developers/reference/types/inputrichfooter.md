# InputRichFooter

A footer text block within rich content. Use this node when sending rich content.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [InputRichText](inputrichtext.md) | Yes | The footer text displayed below the preceding rich content. |
| `type` | `"footer"` | Yes | The rich content node type is footer. |

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
