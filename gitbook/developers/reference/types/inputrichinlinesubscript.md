# InputRichInlineSubscript

Inline text displayed as a subscript. Use this node when sending rich content.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [InputRichText](inputrichtext.md) | Yes | The inline text displayed as a subscript. |
| `type` | `"subscript"` | Yes | The rich content node type is subscript. |

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
