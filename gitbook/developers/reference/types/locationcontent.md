# LocationContent

The location content returned within a message.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `location` | [Location](location.md) | Yes | This contains geographic coordinates and any live location settings. |
| `type` | `"location"` | Yes | The content type is location. |
