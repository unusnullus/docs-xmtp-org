# DiceValue

The allowed dice emoji and result range reported by the platform.

You receive one of the following forms. Required fields apply within each form.

**When `emoji` is `"🎲"`:**

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `emoji` | `"🎲"` | Yes | This is the emoji used for the reaction, dice, or effect. |
| `value` | integer | Yes | This is the dice result or numbering value for the list item. The minimum is 1. The maximum is 6. |
