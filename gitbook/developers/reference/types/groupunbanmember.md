# GroupUnbanMember

Arguments for members.unban in Super Groups with group moderation enabled. Current membership, permissions and promotion ancestry control the operation.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `only_if_banned` | boolean | No | Whether to unban only an account that is currently banned. The default is `false`. |
