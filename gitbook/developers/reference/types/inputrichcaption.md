# InputRichCaption

The text and optional credit associated with rich media. Use this node when sending rich content.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `credit` | [InputRichText](inputrichtext.md) | No | This is the attribution displayed with the quotation or media. |
| `text` | [InputRichText](inputrichtext.md) | Yes | The caption text displayed with this rich media item. |

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
