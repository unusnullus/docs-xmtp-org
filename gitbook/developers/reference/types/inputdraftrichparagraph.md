# InputDraftRichParagraph

A paragraph of inline rich text. Use this node in a temporary rich draft.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | [InputDraftRichText](inputdraftrichtext.md) | Yes | The paragraph's inline text, in reading order. |
| `type` | `"paragraph"` | Yes | The rich content node type is paragraph. |

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
