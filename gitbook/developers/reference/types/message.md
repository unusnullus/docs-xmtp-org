# Message

A content message or a service message available to your bot.

You receive one of the following forms. Required fields apply within each form.

- `kind` is `"content"`: [ContentMessage](contentmessage.md).

- `kind` is `"service"`: [ServiceMessage](servicemessage.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
