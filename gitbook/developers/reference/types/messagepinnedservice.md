# MessagePinnedService

A service event identifying a message that was pinned.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `message` | [Message](message.md) | Yes | This is the message associated with the event or reply. |
| `type` | `"message_pinned"` | Yes | The service event type is message_pinned. |
