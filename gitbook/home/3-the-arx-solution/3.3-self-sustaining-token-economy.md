# 3.3 Self-sustaining token economy

The ARX ecosystem is powered by a utility token that links all network participants through shared economic incentives. The token underpins payments, staking, governance, and infrastructure rewards.

### Token utility

* **Users**: Spend tokens to access premium features, VPN, and eSIM services, or to make payments and microtransactions.
* **Validators and relays**: Stake tokens to secure the network and earn rewards proportional to reliability and uptime.
* **Developers and merchants**: Integrate ARX infrastructure and receive ecosystem incentives for maintaining applications or payment gateways.

### Economic cycle

The system operates as a closed economic loop. User activity funds node operators and developers. Validators maintain uptime and privacy to maximize returns. The DAO treasury redistributes network fees and penalties to sustain the ecosystem.

This model eliminates reliance on advertising or data sales. Instead, value is generated by the operation and reliability of the network itself. Privacy and stability are no longer costs; they become measurable, rewarded outcomes.
