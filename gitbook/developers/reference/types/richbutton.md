# RichButton

An interactive button embedded in rich content.

You receive one of the following forms. Required fields apply within each form.

- `type` is `"callback"`: [RichInlineButtonCallback](richinlinebuttoncallback.md).

- `type` is `"url"`: [RichInlineButtonUrl](richinlinebuttonurl.md).

- `type` is `"copy_text"`: [RichInlineButtonCopyText](richinlinebuttoncopytext.md).

- `type` is `"disabled"`: [RichInlineButtonDisabled](richinlinebuttondisabled.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
