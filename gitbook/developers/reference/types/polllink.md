# PollLink

An HTTP or HTTPS link attached to a poll option.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `type` | `"link"` | Yes | The content type is link. |
| `url` | string | Yes | The HTTP or HTTPS link attached to this poll option. The format is `uri`. |
