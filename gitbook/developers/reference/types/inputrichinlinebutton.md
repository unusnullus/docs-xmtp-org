# InputRichInlineButton

An interactive button within inline rich text. Use this node when sending rich content.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `button` | [InputRichButton](inputrichbutton.md) | Yes | This defines an interactive button embedded in rich text. |
| `type` | `"button"` | Yes | The button action type is button. |

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
