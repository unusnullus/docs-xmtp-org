# AlbumItem

One supported media item in an album request.

Supply exactly one of the following forms. Required fields apply within each form.

- When `type` is `"photo"`, use [AlbumPhoto](albumphoto.md).

- When `type` is `"video"`, use [AlbumVideo](albumvideo.md).

- When `type` is `"live_photo"`, use [AlbumLivePhoto](albumlivephoto.md).

- When `type` is `"audio"`, use [AlbumAudio](albumaudio.md).

- When `type` is `"document"`, use [AlbumDocument](albumdocument.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
