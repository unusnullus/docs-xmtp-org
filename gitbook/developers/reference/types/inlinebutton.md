# InlineButton

An inline keyboard button. Its type determines what happens when it is pressed.

You receive one of the following forms. Required fields apply within each form.

- `type` is `"callback"`: [InlineButtonCallback](inlinebuttoncallback.md).

- `type` is `"url"`: [InlineButtonUrl](inlinebuttonurl.md).

- `type` is `"copy_text"`: [InlineButtonCopyText](inlinebuttoncopytext.md).

- `type` is `"disabled"`: [InlineButtonDisabled](inlinebuttondisabled.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
