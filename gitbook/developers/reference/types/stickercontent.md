# StickerContent

A message containing a sticker file.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `sticker` | [StickerFile](stickerfile.md) | Yes | This contains the regular sticker file or source for the content. |
| `type` | `"sticker"` | Yes | The content type is sticker. |
