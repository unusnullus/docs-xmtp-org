# InputDraftRichInlineEmail

An email link within rich text. Use this node in a temporary rich draft.

Only the listed fields are allowed.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `text` | string | Yes | The email address displayed as an email link. |
| `type` | `"email"` | Yes | The rich content node type is email. |

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
