# TopicDeletionResult

Deletion progress under the contract for the selected chat kind.

You receive one of the following forms. Required fields apply within each form.

- Accepted topic retirement: [PrivateTopicRetired](privatetopicretired.md).

- Progress of an accepted group topic purge: [GroupForumDeletion](groupforumdeletion.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
