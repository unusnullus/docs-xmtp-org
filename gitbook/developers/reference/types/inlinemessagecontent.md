# InlineMessageContent

Content sent as the human who selected the result.

Supply exactly one of the following forms. Required fields apply within each form.

- When `type` is `"text"`, use [InlineText](inlinetext.md).

- When `type` is `"rich"`, use [InputRich](inputrich.md).

- When `type` is `"location"`, use [InputLocation](inputlocation.md).

- When `type` is `"venue"`, use [InputVenue](inputvenue.md).

- When `type` is `"contact"`, use [InputContact](inputcontact.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
