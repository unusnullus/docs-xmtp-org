# ContactContent

The contact card content returned within a message.

| Field | Type | Required | Description and constraints |
| --- | --- | --- | --- |
| `contact` | [Contact](contact.md) | Yes | This is the contact card shared in the message. |
| `type` | `"contact"` | Yes | The content type is contact. |
