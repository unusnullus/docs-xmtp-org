# TopicMutationResult

The resulting private topic or group forum topic, selected by the chat kind.

You receive one of the following forms. Required fields apply within each form.

- Private topic metadata: [PrivateTopic](privatetopic.md).

- Metadata and current capabilities of a group forum topic: [ForumTopic](forumtopic.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
