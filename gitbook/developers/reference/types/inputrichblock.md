# InputRichBlock

One supported rich content block. Use this node when sending rich content.

Supply exactly one of the following forms. Required fields apply within each form.

- When `type` is `"heading"`, use [InputRichHeading](inputrichheading.md).

- When `type` is `"paragraph"`, use [InputRichParagraph](inputrichparagraph.md).

- When `type` is `"footer"`, use [InputRichFooter](inputrichfooter.md).

- When `type` is `"divider"`, use [InputRichDivider](inputrichdivider.md).

- When `type` is `"preformatted"`, use [InputRichPreformatted](inputrichpreformatted.md).

- When `type` is `"math"`, use [InputRichMath](inputrichmath.md).

- When `type` is `"blockquote"`, use [InputRichBlockquote](inputrichblockquote.md).

- When `type` is `"expandable_blockquote"`, use [InputRichExpandableBlockquote](inputrichexpandableblockquote.md).

- When `type` is `"pull_quote"`, use [InputRichPullQuote](inputrichpullquote.md).

- When `type` is `"details"`, use [InputRichDetails](inputrichdetails.md).

- When `type` is `"reference"`, use [InputRichReference](inputrichreference.md).

- When `type` is `"anchor"`, use [InputRichAnchor](inputrichanchor.md).

- When `type` is `"list"`, use [InputRichList](inputrichlist.md).

- When `type` is `"table"`, use [InputRichTable](inputrichtable.md).

- When `type` is `"photo"`, use [InputRichPhoto](inputrichphoto.md).

- When `type` is `"video"`, use [InputRichVideo](inputrichvideo.md).

- When `type` is `"animation"`, use [InputRichAnimation](inputrichanimation.md).

- When `type` is `"audio"`, use [InputRichAudio](inputrichaudio.md).

- When `type` is `"voice"`, use [InputRichVoice](inputrichvoice.md).

- When `type` is `"document"`, use [InputRichDocument](inputrichdocument.md).

- When `type` is `"collage"`, use [InputRichCollage](inputrichcollage.md).

- When `type` is `"slideshow"`, use [InputRichSlideshow](inputrichslideshow.md).

- When `type` is `"map"`, use [InputRichMap](inputrichmap.md).

- When `type` is `"buttons"`, use [InputRichButtons](inputrichbuttons.md).

Return to the [type index](../types.md) or find an operation in the [API index](../../api.md).
